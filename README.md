# ck-you3

A free desktop app for macOS and Windows that imports the YouTube watch history you export
from Google Takeout, lets you browse and search it, and saves the songs you pick as MP3 files
to a folder or a USB drive. Everything runs on your computer: nothing is uploaded, and there
is no account.

## Download

- macOS (Intel and Apple Silicon): [https://github.com/ckandrinirina/ck-you3/releases/latest/download/ck-you3-mac.dmg](https://github.com/ckandrinirina/ck-you3/releases/latest/download/ck-you3-mac.dmg)
- Windows: [https://github.com/ckandrinirina/ck-you3/releases/latest/download/ck-you3-windows-setup.exe](https://github.com/ckandrinirina/ck-you3/releases/latest/download/ck-you3-windows-setup.exe)

The installers are not signed yet, so the first launch asks for one extra step: on macOS,
open System Settings → Privacy & Security and choose "Open Anyway"; on Windows, choose
"More info" → "Run anyway".
