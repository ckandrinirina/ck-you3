Notes de version

Toutes les versions de ck-you3, de la plus récente à la plus ancienne.

v0.3.1

9 octobre 2026

Modifications

  • The app is smaller to download and install. The macOS installer drops from about 221 MB to 206 MB, and the installed app from 522 MB to 465 MB. It now carries only the English and French language files and no longer bundles a second copy of its interface libraries and fonts.

Sécurité

  • The installed app can no longer be started as a plain Node.js process or opened with a debugger, and it refuses to start if its bundled code has been altered.
  • The app's own code is shipped minified, without source maps.

The installers are still not signed. On macOS, open the app once with right-click → Open (or System Settings → Privacy & Security → "Open anyway"); on Windows, choose "More info" → "Run anyway".

v0.3.0

9 octobre 2026

Ajouts

  • An "Install tools" button: when yt-dlp or ffmpeg is missing, one click downloads and installs them into the app's own folder, with progress. yt-dlp is checked against its published checksums before it is used.
  • Settings shows which yt-dlp the app uses, its version and where it came from, and can update a copy the app installed.
  • The app now checks for new versions when it starts and every six hours. It shows what is new and lets you update now, later, or skip that version. Nothing is downloaded until you choose Update.
  • Settings shows the running version and has a "Check for updates" button.

Modifications

  • Tools you already installed, for example with Homebrew, are now found even when the app is opened from Finder or the Dock.
  • yt-dlp is given a JavaScript runtime (deno) it can find. If deno is missing you get a warning, not an error.

Notes

  • Updating from 0.2.0 is manual this time: download this release from the site. From 0.3.0 on, the app offers new versions itself. On Windows it installs them in place; on macOS it downloads the new installer, checks it and opens it for you.

The installers are still not signed. On macOS, open the app once with right-click → Open (or System Settings → Privacy & Security → "Open anyway"); on Windows, choose "More info" → "Run anyway".

v0.2.0

8 octobre 2026

Ajouts

  • Settings now ends with an About section: who makes ck-you3, the app version, and links to email, GitHub and LinkedIn that open in your browser.

Modifications

  • A new app icon: a soundwave and a connected pulse on a dark tile, in the Dock, the Start menu and the taskbar.
  • The app's top bar shows the same mark beside the CK-YOU3 wordmark.

The installers are still not signed. On macOS, open the app once with right-click → Open (or System Settings → Privacy & Security → "Open anyway"); on Windows, choose "More info" → "Run anyway".

v0.1.0

7 octobre 2026

Ajouts

  • The first public release of ck-you3, for macOS (one universal DMG for Intel and Apple Silicon) and Windows.
  • Import the watch history you exported from Google Takeout, then browse and search it.
  • Pick tracks and save them as MP3 files to a folder, or to a USB drive the app detects.
  • Everything stays on your computer: no account, no server, nothing uploaded.

The installers are not signed yet. On macOS, open the app once with right-click → Open (or System Settings → Privacy & Security → "Open anyway"); on Windows, choose "More info" → "Run anyway".
